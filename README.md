# بوتيك لندن للأزياء | London Fashion POS & Accounting

نظام محاسبي ونقطة بيع سحابية متكاملة مخصصة لمتاجر الملابس والأزياء الراقية، مبني بأحدث تقنيات الويب السريعة (React 19 + Vite + Tailwind CSS + Supabase).

## 🌟 المميزات الرئيسية

### 1. الكاشير السريع ونقطة البيع (POS)
- **مصفوفة المقاسات والألوان**: دعم كامل لمقاسات الملابس (S, M, L, XL, XXL, 38, 40...) والألوان مع رصيد كل مقاس.
- **قارئ الباركود الصوتي**: قراءة سريعة لباركود الأصناف مع صوت تنبيه إلكتروني بدون ملفات صوت خارجية.
- **طرق دفع متعددة**: كاش (نقداً)، شبكة / بطاقة (مدى / فيزا)، آجل / ذمم (ديون العملاء)، ودفع مجزأ.
- **حاسبة الفكة الفورية**: حساب تلقائي للمبلغ المتبقي للعميل مع أزرار الفئات النقدية السريعة (50، 100، 200، 500).
- **تعليق الفواتير (Hold Orders)**: إمكانية تعليق الفاتورة لخدمة زبون آخر واستعادتها بلمسة زر.
- **طباعة إيصالات حرارية 80mm**: متوافقة مع جميع طابعات الكاشير الحرارية والـ QR Code و A4.
- **اختصارات لوحة المفاتيح السريعة**:
  - `F1`: فاتورة جديدة
  - `F9`: تعليق الفاتورة
  - `F12`: إتمام عملية البيع والدفع

### 2. إدارة حقوق الشركاء والأرباح (Partners Capital & Profit Sharing)
- تسجيل الشركاء مع نسب الملكية ورأس المال الأولي.
- حساب تلقائي لصافي أرباح المحل القابلة للتوزيع: (المبيعات - تكلفة الشراء COGS - المصروفات).
- توزيع الأرباح تلقائياً بدقة حسب نسبة كل شريك (مثل أحمد الزعبي 60%، خالد محمد 40%).
- تتبع ومراقبة مسحوبات الشركاء مع كشف حساب فوري وصافي المستحق لكل شريك.

### 3. الفواتير والمرتجعات (Invoicing & Returns)
- سجل كامل لجميع فواتير المبيعات مع فلاتر البحث وإعادة الطباعة.
- نظام استرجاع واستبدال ذكي: يعيد القطع والمقاسات تلقائياً للمخزون، ويعدل نقدية الصندوق أو رصيد ديون العميل.

### 4. إدارة المخزون والأزياء (Clothing Inventory)
- بطاقة صنف متطورة للملابس تشمل: الاسم، الكود SKU، الباركود، الفئة، التكلفة، سعر البيع، هامش الربح %.
- تنبيهات تلقائية لنواقص المخزون والأصناف التي قاربت على النفاد.

### 5. التحليلات والتقارير المالية (Analytics)
- إجمالي المبيعات، تكلفة البضاعة، المصروفات التشغيلية، وصافي الأرباح.
- تقرير الموديلات والأزياء الأكثر مبيعاً والأعلى تحقيقاً للإيرادات.
- توزيع طرق الدفع (كاش مقابل شبكة مقابل آجل).

### 6. العملاء والديون والمصروفات
- سجل العملاء والديون مع تسجيل دفعات السداد فورياً.
- سندات الصرف للمصروفات اليومية (إيجار، كهرباء، رواتب، تغليف...).

### 7. المزامنة والنسخ الاحتياطي
- تكامل مباشر مع قاعدة بيانات Supabase للمزامنة السحابية المركزية.
- العمل بدون توقف حتى عند انقطاع الإنترنت (Offline-Ready).
- تصدير واستيراد قاعدة البيانات بنقرة واحدة بصيغة JSON.

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

- رابط التطبيق المحلي: `http://localhost:5173`
- رابط الشبكة المحلية: `http://192.168.0.101:5173`
